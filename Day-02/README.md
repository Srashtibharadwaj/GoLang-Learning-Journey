# Day 2 — Go Programming

## 📚 What I Learned

On Day 2 of my Go learning journey, I practiced control flow and learned how constants are used in Go programs.

### Topics Covered

* **Constants** — Declaring and using constant values
* **For Loop** — Repeating a block of code using a loop
* **Nested For Loop** — Using a loop inside another loop
* **If-Else** — Making decisions based on conditions
* **Switch** — Handling multiple possible conditions
